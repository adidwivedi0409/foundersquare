# Logos

Founder Square logo files, one colour each. `-dark` files are drawn in `bone` (#ece8df) for dark grounds; `-light` files in `ink` (#141414) for paper. Horizontal is the default lockup, stacked for square spaces, the mark alone for the header and small sizes (16px minimum). `favicon.svg` is the mark on an `ink` tile for browser tabs and app icons. Rules: see Identity.
