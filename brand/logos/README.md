# Logos

The Founder Square logo: the red mark and "founder square" in Plus Jakarta Sans ExtraBold, outlined, one colour each. `logo-red` (#e42425) is the default on white, `bg` and black; `logo-white` goes on red; `logo-black` is for one-colour print. `mark-*` is the mark alone; `favicon.svg` is the red mark for browser tabs. Rules: see Identity.
