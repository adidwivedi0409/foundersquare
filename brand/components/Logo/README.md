# Logo

The Founder Square mark and wordmark; use the supplied SVGs, never retype or redraw them.

**Files.** `brand/logos/`: `logo-horizontal-*` (default), `logo-stacked-*` (square-ish spaces, the footer, social avatars with room), `mark-*` (the header, small spaces), `favicon.svg` (browser tabs, app icons; the mark on an `ink` tile). `-dark` files are `bone` ink for dark grounds, `-light` files are `ink` for paper.

**Construction.** The mark sits on an 8×8 module grid: a 2-module top bar, a 2-module stem, a 5×5 block, 1-module channels between them (the panel grid's gutter, scaled up), and a 2×1 notch cut from the block's left edge. The wordmark is Instrument Sans 500 in caps at −0.03em. Horizontal: caps span the block (modules 3–8), 2 modules after the mark. Stacked: FOUNDER sits on rows 0–3, SQUARE on rows 5–8.

**Clear space.** At least 2 modules (a quarter of the mark's height) on every side; in the header the mark sits in its own panel, which gives it that.

**Minimum size.** Mark 16px (2px per module). Horizontal lockup 20px tall. Stacked lockup 32px tall.

**Colour.** One colour only: `fg` on `bg`. Never amber, never two-tone, never on a line-art scene or a photo, never with a shadow or outline.

**Don't.** Stretch, rotate, round the corners, change the channel widths, set the name in another face, add "The", or use lowercase in the lockup. In running text and the header the name is set in type: "Founder Square".
