# Button

A square red block with a white label; the one way to take the main action on a view.

**Variants.** `.button`: `red` fill, white `button-label` text, 52px minimum height, 14px × 24px padding. `.button.light`: `bg` fill with `ink` text, for use on `black` or `red` bands.

**Rules.** One or two per view. Verb first, ends with " ↗" when it opens a page or an email ("Register for Build Night ↗"). Hover lifts 3px; no icons, no rounded corners.
