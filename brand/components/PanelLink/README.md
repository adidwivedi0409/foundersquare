# PanelLink

A whole grid cell that is a link: it inverts to the figure colour on hover.

**Markup.** `<a class="panel-link">` as a child of a `.grid`, label left, arrow right. Add `.cell-accent` for the one amber panel in a group (it stays amber on hover). Inside `.scheme-paper` the inversion flips the other way automatically.

**Use** for rows of destinations: email the team, propose an event, footer links, an open seat. Use `Button` when the action sits inside a cell rather than being the cell.
