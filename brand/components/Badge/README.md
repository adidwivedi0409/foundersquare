# Badge

An outlined mono tag that marks anything not real yet: "Placeholder", "Form link TBD", "Draft".

**Markup.** `<span class="badge">` after the text it qualifies; 1px `currentColor` border, so it takes the colour of the line it sits in (amber-ink on an accent panel).

**Rules.** Every unconfirmed name, venue, sponsor or link carries one until it is real, so nobody ships a fake. Short, uppercase, never a pill.
