# CtaBand

The closing band: a live `runway` line-art scene, two counter-scrolling rows of display type knocked out of it, and an amber arrow panel.

**Parts.** `canvas` (runway scene), `.cta-rows > .row` in `display`, the two halves of one sentence ("Let's build —" / "Something at 1 AM —") repeated and scrolling in opposite directions, each phrase on a `bg` panel so it reads over the lines, the dash in `<i>` amber, `.arrow-panel` (amber square with `amber-ink` arrow), `.band-label` chips. The whole band is one link.

**Use** once per page, at the end, linking to the main ask.
